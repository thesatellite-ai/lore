lore setup

The guided setup page comes with lore EE. This lore is a build without it (a source build of the open core), so it serves the setup API only:

version
{{.Version}}
binary
{{.Path}}

Open the guided page

Run lore setup with the released lore (a preview build: lore-dev setup). If the released lore is not installed, install it with Homebrew (brew install thesatellite-ai/tap/lore), the install script (curl -sL https://raw.githubusercontent.com/thesatellite-ai/lore/main/install.sh | sh) or an archive from the releases page. If it is installed, check which lore comes first on your PATH: it may be this build.

Or set up from the command line

Every step is available from the command line with this build:

lore setup plan
show the steps a setup needs and the values it will use
lore setup check
run the checks of a setup and show what passes and what fails
lore setup apply
save the setup and run its steps
lore doctor --all
check every setup on this machine

Add --help to any of them for the flags. You can close this tab; the server stops after its idle minutes or when you press Ctrl-C in the terminal.

lore setup

The guided setup page comes with lore EE. This build of lore serves the setup API only, so every step is available from the command line instead:

lore setup plan
show the steps a setup needs and the values it will use
lore setup check
run the checks of a setup and show what passes and what fails
lore setup apply
save the setup and run its steps
lore doctor --all
check every setup on this machine

Add --help to any of them for the flags. You can close this tab; the server stops after its idle minutes or when you press Ctrl-C in the terminal.

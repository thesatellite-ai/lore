### api rotate
alice$ cp .lore/api-token old-token
alice (work/website)$ lore api token rotate
new token written to ~/.lore/api-token
alice$ curl -s -o /dev/null -w "old token: HTTP %{http_code}\n" -H "Authorization: Bearer $(cat ~/old-token)" http://127.0.0.1:$PORT/v1/rules
